# Mobile Maia 2.5.0 — proposed Stable release

Android version code: **82**. Prepared 27 October 2026.

**This is PR preparation. Stable 2.5.0 has not been built, signed, tagged or
published by this work.** Existing download links continue to point to published
releases. Follow [RELEASING.md](../RELEASING.md) before any later publication.

## What's new since Stable 2.4

- **Appearance:** Settings offers Light, Dark or System default, optional Android system colors on supported Android 12+ devices, and Pure black background for dark mode. The original green/dark theme remains the default. Pure black retains its choice in light mode; it only changes dark backgrounds.
- **Board choices and aids:** Settings → Board includes 25 fixed offline boards and 16 approved piece sets with previews. Coordinates, legal-move destinations, last-move highlighting, animation, dragged-piece magnification and Circle/Square/None drag targets can be set independently. Brown/Cburnett and existing aid defaults are retained. This uses the audited artwork subset; it does not expose every upstream piece set.
- **New-install and reset defaults:** Play Maia and primary analysis use 1500, with 2600 for the optional second engine. Temperature is 1.0, Top-P is 0.95 and Max variety in opening is on. The first five moves by each side use 1.0/1.0, then the configured values apply from move 6. Existing explicit preferences and frozen saved-game profiles keep their values; old games are not silently opted into the opening override. The second engine remains off by default.
- **Clearer engine help:** one scrollable Temperature and Top-P guide combines plain-language examples, technical explanations, opening probabilities, cumulative Top-P filtering, the opening override and research links in all ten languages. Earlier 2.5 Preview Simple/Technical selectors were replaced before this promotion. Temperature 0 explicitly marks Top-P unused. Shorter move-history help preserves the off recommendation and the distinction between prediction accuracy and playing strength.
- **Graphical Board Editor:** black/white palettes, move/place/erase tools, tap and drag editing, flip, a position-settings sheet and FEN copy/share. Side to move, independent castling rights, en-passant and move counters are preserved. Incomplete drafts remain editable; Analysis and Continue validate the position. Image import remains explicitly unavailable.
- **Optional Maia expected score:** Settings → Analysis → **Show Maia win (score) %** is off by default. Analysis Board and Game Review can show each Maia engine's rating, side disc and percentage in the existing title area. Fixed columns prevent labels/discs moving as values load or change. Tap for accessible details; narrow screens may hide the visual rating while retaining it in details.
- **Better analysis navigation:** taps step through the current line. In a side variation, hold Left returns to the outermost main-line branch point; hold Right selects the next main-line move after that point, clamped at the game end. At a variation end, the dimmed Right control still accepts a hold. On the main line, holds retain beginning/end behavior. Navigation clears stale selection, destination dots, held drags and promotion state, while ordinary engine updates preserve selection.
- **Continue on Chessnut:** Continue from here can connect to or reuse a Chessnut board, with Retry, Cancel and phone fallback. Set up board starts an untimed continuation and waits for physical pieces to match the selected position, with mismatch LED guidance. Full FEN, turn, castling/en-passant rights, rating and validated history are retained. Switching the option off restores the selected phone clock. Connection ownership and stale-command handling protect covered games during handoff and cancellation.
- **Translation and platform maintenance:** clearer theme and chess/sampling wording in all ten languages, light/dark Android system surfaces, and the reviewed Flutter 3.47.8 / Dart 3.13.7 security toolchain update. The dependency review is recorded separately; preparing this source does not qualify a release artifact.

Maia's percentage is **expected game score**, `P(win) + ½ × P(draw)`, not a
literal probability of winning. White 60% means about 60 expected points in 100
games, counting draws as half a point. Each engine conditions on its own
analysis rating for both players: M1500 is 1500 versus 1500, rather than one
engine assigned to White. This estimate is distinct from Maia move-choice
probabilities and Stockfish's evaluation. Equal rounded scores show `= 50%`,
loading an ellipsis, unavailable values a dash and terminal positions the
actual result. Temperature and Top-P do not set this percentage.

## Promotion scope and acceptance

The proposed app behavior follows Preview 2.5.0-beta.10 source
`96745a6e49c1b66962b2219ebb23e35a5a1ef1a4` and Preview main
`e1688ddb8e404716961824dfc9e51d992b238a16` (publication documentation), subject
to the final source audit. Stable keeps its unflavored
`com.dash1971.maia_chess` package, blue identity, 79M model, existing signing
identity and Stable release gates. Preview/Dev identities and the Dev 5M model
are not promoted. Existing DGT Pegasus and Square Off Grand Kingdom prototype
source remains present but blocked in Stable. Timed physical-board
games, USB and direct physical editing/input in Analysis Board remain outside
this feature.

The requester reports that the Chessnut tests passed and authorized this PR
preparation. That is **user-reported hardware acceptance**; the preparer has not
independently tested physical Bluetooth, LEDs or a board. Archived Preview
emulator and controlled-transport qualification are separate evidence, not
substitutes for physical testing or exact-source Stable qualification.

Existing settings, games, analysis trees and sampling data are intended to be
preserved. A later release must verify the actual signed Stable 2.4 → 2.5 upgrade;
Preview upgrade evidence alone does not establish that result.
