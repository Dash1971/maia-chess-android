# Mobile Maia 2.4.0

Prepared for review; **not published**. Android version code: **81**.

## What's new

- **Max variety in opening:** an optional switch keeps Temperature and Top-P at 1.0 for each side's first five moves, then returns to your chosen values from move 6. It is off by default and unavailable when both controls are already at 1.0. The idea is inspired by [Maia3-tauri](https://github.com/outusuke/maia3-tauri) by outusuke; Mobile Maia implements its own five-move behavior.
- **Understand Maia's choices:** optionally save sampling data and export a readable offline HTML report or full JSONL data. Reports show actual selection probabilities after the settings are applied, odds, move arrows and game headings. The latest ten recorded games are retained, including unfinished games, newest first, subject to a 64 MiB safety limit. Capture is off by default; it is separate from Recent games.
- **Clearer Settings:** separate game, engine, analysis and Chessnut sections, revised help in all ten languages, and a confirmed reset of settings that preserves saved games and captures. Experimental move-history input is available but off is still recommended; our tests did not establish a strength gain.
- **Better Chessnut play:** single/multiple-board discovery, remembered selection, named connection messages and improved reconnect/recovery. Press the physical NEW GAME button twice within 2.5 seconds to confirm an in-game reset, keep the colors and wait for the LED-guided physical setup. Experimental DGT Pegasus and Square Off Grand Kingdom remain blocked in Stable.
- **Smoother multiple premoves:** projected pieces stay in place as queued moves are consumed, with highlights showing the remaining queue.
- **Cleaner review navigation:** long opening names stay on one line and show a details action only when truncated. Home returns directly from restored post-game analysis.
- **Research has a dedicated home:** app help and current documentation link to [Mobile Maia research](https://github.com/Dash1971/mobile-maia-research). Old app report/index URLs retain relocation notices. The verified duplicate research bundle is removed from the current app source without rewriting old releases.

The Maia3 79M model, Stockfish 19 Light, default Temperature/Top-P 1.0/1.0,
ten languages, Stable package identity and signing identity are retained.
The Gradle security update to 9.8.1 and its checksum guard are included.
