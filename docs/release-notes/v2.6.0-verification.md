Installed ARM64 checks covered 22 native integration cases, real Maia/Stockfish,
production-signed 2.5.1 upgrade with saved data and preferences, and three saved-game
fixture upgrades. Changed-feature checks covered graph/annotation persistence,
reopening, Save/Share/Copy with analysis on and off, document-provider imports,
near-5-MiB collections and overflow handling. Fresh human timing defaults on;
an explicitly saved off preference survives upgrade. Grand Kingdom has passed
user acceptance testing; this release did not repeat physical-board testing.
Emulator checks do not substitute for physical tablet usability testing.

retained in the evidence. Final checks used the unchanged frozen app source/APK;
they do not turn failed attempts into passes. The operator upgrade-driver adapter
is recorded separately; no shared verification helper was changed in this release.
