# Mobile Maia 2.6.0

**Grand Kingdom support, better game review, easier game management, and safer recovery.**

- **Square Off Grand Kingdom support.** Play Maia on your electronic board in untimed games from the standard starting position. Maia's promotions use assisted piece replacement and confirmation. Chessnut Air, Go and Pro are supported; Pro awaits further hardware testing.
- **More room for chess.** Larger landscape boards and adaptive Home and Settings layouts make better use of phones and wider screens.
- **Analysis stays visible.** Engine output and moves have separate panes. Scroll, step through moves, or hold either navigation arrow without pushing engine analysis offscreen. Landscape Moves and Computer analysis controls share the bottom strip.
- **A cleaner Recent games screen.** Compact columns, consistent yyyy/MM/dd dates, centered results and clear Incomplete labels. Back cancels selection first; returning from a saved game restores your list position. Deletion is available from the selection toolbar instead of an icon on every row. Back from an unfinished game retains the leave confirmation.
- **Transfer game collections.** Select individual games or Select all, then save or share one PGN file with supported headers, comments, clocks and variations. Import and export both allow 5 MiB. Importing a collection adds new games to Recent games without replacing the current game, skips identical PGNs and reports both counts; single-game PGNs still open for analysis. PGN transfers games and annotations, not app settings or live clock/board session state. Oversized or unreadable selections do not produce a partial collection.
- **Safer recovery.** Damaged temporary saves no longer hide the committed game. Opening another game or importing PGN keeps an interrupted game in Recent games with its original identity, moves and clock. After a crash, choose its Incomplete entry to reopen it.
- **Resume interrupted computer analysis.** Analysis pauses when Review is covered or the app is backgrounded, then resumes unfinished work when the same open Review returns. Explicit Stop, engine-off, line changes and quality changes cancel the pending run. Completed reports are not newly persisted across app restarts.
- **Human move timing on by default.** Unset preferences now enable timing, including after upgrading from 2.5.1. An explicitly saved off choice remains off; Settings resets enable timing. Maia's move selection and clock rules are unchanged.
- **Additional fixes.** Android Back handling, board-neutral Bluetooth/permission messages, a specific error for an oversized individual PGN, Maia score visibility when engines are off, and reviewed build-tool security updates.

Mobile Maia remains free, open source and offline, with the same Maia-3 79M model. Your existing games and settings are intended to be preserved. DGT Pegasus is withdrawn from all channels because initialization licensing is unresolved. Automatic Dev diagnostics remain unavailable in Stable. Camera/image board recognition is not included.

Grand Kingdom requires standard-position setup. Assisted promotion needs physical piece replacement and explicit confirmation. Interrupted motor movement and takebacks use phone continuation; arbitrary-position motor restoration and automatic move replay are not added by this release.
