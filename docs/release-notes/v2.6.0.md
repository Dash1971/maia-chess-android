# Mobile Maia 2.6.0

- Square Off Grand Kingdom support with assisted Maia promotion.
- Saved PGN analysis: reopen games with their evaluation graphs and move annotations.
- Include or omit analysis when saving, sharing or copying PGN.
- Import and export PGN collections up to 5 MiB, with duplicate checking.
- Import complete collections from Recent games; open individual games in Analysis Board.
- Larger landscape boards and improved phone and tablet layouts.
- Compact Recent games with yyyy/MM/dd dates and centered results.
- Back cancels selection and returns saved games to the same list position.
- Human move timing on by default.
- Fixes for saving, recovery, move navigation and translations.
