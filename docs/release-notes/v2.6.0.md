# Mobile Maia 2.6.0

**Grand Kingdom support, saved analysis, more room for chess, and easier game management.**

- **Square Off Grand Kingdom support.** Play Maia on your electronic board in untimed games from the standard starting position. Maia's promotions use assisted piece replacement and confirmation. Grand Kingdom has passed user acceptance testing. Chessnut Air, Go and Pro are supported; Air and Go are fully tested, while Pro awaits further hardware testing.
- **Save computer analysis with your games.** Completed evaluations and move-quality annotations are stored in the game's PGN. Reopen the game to restore its evaluation graph and markings without another full-game analysis run. Ordinary selected-position engine analysis remains available. Explicit reanalysis replaces earlier scores and quality symbols on that line, preserving prose comments, clocks and variations.
- **Choose what to export.** **Include analysis** is checked by default in the existing Save/Share/Copy menu and Recent games collection export. Uncheck it to remove evaluation tags and the six move-quality symbols from the exported copy. Stored games keep their analysis; ordinary comments, clocks, variations and other positional annotations remain. There is no extra popup or persistent export setting. Analysis stripping runs in a background worker, including Copy PGN.
- **Reuse compatible imported analysis.** When every move has a readable evaluation but the initial score is absent, evaluate just that starting position and restore the graph. Missing or malformed evaluations elsewhere do not prevent opening the game, but are not filled automatically.
- **More room for chess.** Larger landscape boards and adaptive Home and Settings layouts make better use of phones and wider screens. Engine output and moves have separate panes: scroll, step through moves, or hold either navigation arrow without pushing analysis offscreen. Landscape Moves and Computer analysis controls share the bottom strip.
- **A cleaner Recent games screen.** Compact columns, yyyy/MM/dd dates, centered results and clear gray Incomplete labels. Back cancels selection first. Returning from a saved game restores the same list position; Home still returns Home. Delete selected games from the selection toolbar. The unfinished-game leave confirmation remains.
- **Transfer PGN collections.** Save or share selected Recent games as one PGN file. **Recent games → Import PGN** imports every game, including single-game files. Import and export both allow 5 MiB. Identical PGNs are skipped, with imported/skipped counts and delayed progress feedback for longer imports. Different dates, names and annotations remain distinct. Validation or storage failure exposes no partial collection, and oversized exports retain selection for retry.
- **Open a game for analysis.** **Analysis Board → Open PGN file / Load PGN** opens only the first game in a collection and explains where to import the full set. An invalid later game cannot prevent the first valid game opening. Android Open with and shared attachments keep their existing routing.
- **Safer recovery.** Damaged temporary saves no longer hide the committed game. Opening another game or importing PGN retains interrupted play in Recent games with its identity, moves and clock. Returning Home prevents a background autosave from creating a duplicate copy during the transition. Existing saved games are not silently merged or deleted.
- **Resume unfinished analysis.** When the same open Review returns from another screen or the background, unfinished analysis resumes. Explicit Stop, engine-off, line changes and quality changes cancel pending work. Completed evaluations and markings now survive reopening through PGN; unfinished per-position work is not saved as a restartable report cache.
- **Human move timing on by default.** Unset preferences enable timing, including after upgrading from 2.5.1. An explicitly saved off choice stays off; Settings resets enable timing. Maia's move selection and clock rules are unchanged.
- **Additional fixes.** Android Back handling, board-neutral Bluetooth/permission messages, distinct per-game and collection export-size errors, Maia score visibility when engines are off, reviewed translations in all ten languages, and build-tool security updates.

Mobile Maia remains free, open source and offline, with the same Maia-3 79M model. Existing games and explicitly saved settings are preserved. PGN transfers games and supported annotations, not app settings or live clock/motor checkpoints. DGT Pegasus is withdrawn because initialization licensing is unresolved. Automatic Dev diagnostics and camera/image board recognition are not included in Stable.

Grand Kingdom uses standard-position setup and untimed play. Assisted promotion requires physical piece replacement and confirmation. Interrupted motor movement and takebacks use phone continuation; arbitrary-position motor restoration and automatic move replay are not added.
