# Mobile Maia 2.1.1

Mobile Maia 2.1.1 is a distribution and reproducibility maintenance release.
It contains the same application features and offline behavior as Mobile Maia
2.1.0.

## Reproducible Linux release

- Build the canonical unsigned universal APK on GitHub Actions Linux from an
  explicitly verified full source commit.
- Retain the unsigned APK hash and sanitized source, runner, Flutter, Java,
  Android NDK, and Clang provenance with the workflow artifacts.
- Require a clean independent Linux rebuild to match the GitHub Actions APK
  byte-for-byte before signing.
- Sign the exact verified Linux artifact locally without rebuilding it, keeping
  the developer signing key off CI and independent build hosts.
- Use the same developer-signed APK for GitHub/Obtainium distribution and
  F-Droid's reproducible developer-signed publication path.

## Upgrade notes

- Mobile Maia 2.1.1 is an in-place update for the stable package
  `com.dash1971.maia_chess`; games and settings are preserved.
- The APK remains universal for ARMv7, ARM64, and x86_64.
- Mobile Maia remains offline and requests no Internet permission.
