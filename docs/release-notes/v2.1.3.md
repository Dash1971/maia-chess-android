# Mobile Maia 2.1.3

Mobile Maia 2.1.3 is a compatibility maintenance release for newer Android
devices. It preserves Mobile Maia's existing features, offline behavior, saved
games, and settings.

## Android 16 inference compatibility

- Update ONNX Runtime for Android from 1.23.2 to 1.24.3.
- Fix a native `SIGILL` crash during Maia inference on affected Android 16
  devices using Snapdragon SM8850-class processors.
- The fix was confirmed by the original Nubia Z80 Ultra reporter using Mobile
  Maia Preview 2.1.0-beta.20 before promotion to Stable.

## Build integrity and reproducibility

- Preserve Stable's R8 rules for ONNX Runtime JNI and reflection entry points.
- Build the canonical unsigned APK on GitHub Actions Linux and require a clean
  independent Linux rebuild to match it byte-for-byte before signing.
- Sign the exact verified Linux artifact locally without rebuilding it; the
  developer signing key remains off CI and independent build hosts.

## Upgrade notes

- Mobile Maia 2.1.3 is an in-place update for the stable package
  `com.dash1971.maia_chess`; games and settings are preserved.
- The APK remains universal for ARMv7, ARM64, and x86_64.
- Mobile Maia remains offline and requests no Internet permission.
