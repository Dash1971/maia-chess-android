# Mobile Maia 2.2.2 — maintenance release

**Release-source notes.** Build and publication results are recorded in the
[GitHub release](https://github.com/Dash1971/maia-chess-android/releases/tag/v2.2.2)
once published; these source notes do not claim F-Droid acceptance.

This release refreshes the F-Droid description, screenshots, and release notes
for the features already shipped in 2.2.1: two Maia analysis ratings, move
probabilities, game feedback, and Continue from here setup.

Play, both Maia analysis controls, and Continue from here now use the documented
600–2600 target-player rating range in 100-point steps. Saved rating defaults of
500 migrate to 600; all saved values already within 600–2600 are preserved.
Existing games retain their original rating when restored, while new games use
the supported range. These ratings describe the human games Maia imitates,
not a calibrated playing strength. Engines, model weights, and dependencies
are unchanged.

Release checks now inspect metadata in an exact Git commit or tag. This catches
missing release notes even when they were added later on `main`. The checks
also require the basic store listing and screenshots, enforce text limits,
and retain the archive guard introduced in PR #33. They add no runtime app
work or dependencies.

## Why a new version

The existing tags do not contain their matching Fastlane changelogs, and their
store listing predates the 2.2 features. A new immutable source release includes
all of that metadata together. Existing tags and APKs must not be replaced.
The source identity is `2.2.2+79`.

This is not a workaround for a failed F-Droid build. The canonical bot-inherited
recipe still needs independent qualification on the final source, and upstream
publication must be observed separately. See [F-Droid readiness](../../FDROID_READINESS.md)
for the pre-publication evidence and release gates. Record final source/build
evidence in the GitHub release after those gates pass.
