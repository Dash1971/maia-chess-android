## Choices requiring contextual review

- Castling editor headings describe retained rights, not immediate legality: German `Rochaderechte`, French `Droits de roque`, Russian `Право на рокировку`. German options use canonical O-O/O-O-O; French and Russian name short/long castling and the side.
- Variation promotion and main-line selection follow the Lichess tree actions. They are distinct from pawn promotion. Material descriptions explicitly mean the difference between the two sides rather than all pieces remaining.
- The six annotation categories preserve the meanings of `!!`, `!`, `!?`, `?!`, `?`, `??`. Russian uses Lichess's `Отличный` and `Зевок`; French uses `Brillant` and `Gaffe`; German uses `Brillant` and `Grober Patzer`. Literature cross-checks support the distinctions. Count labels avoid trying to inflect arbitrary interpolated classification labels.
- Undo completion messages describe the rollback operation without promising exactly one half-move. Premoves mean queued inputs; the 100 ms penalty means a clock deduction. Maia timing means optional pauses, without claiming to model human thinking times.
- Sampling help describes predicted human move choices, not winning chances. Temperature controls concentration; Top-P retains a leading group sorted by probability. Rating describes the modeled player population, not a guarantee of engine strength.
- Russian supplies `one`, `few`, `many`, `other` in all nine plural messages. Regression tests cover 0, 1, 2, 5, 11, 21, 22, 25 and 111. German and French use `one`/`other`; French zero follows its locale's plural rules.
- Hindi follows familiar Lichess/Indian chess piece names: राजा, वज़ीर, हाथी, ऊँट, घोड़ा, प्यादा. It uses कैसलिंग के अधिकार for retained castling rights. Older or awkward Lichess wording is adapted where needed; variation promotion explicitly changes the analysis tree. टेम्परेचर names the sampling parameter consistently. Explicit `=0` branches prevent singular pawn/knight/move wording at zero; selected-game counts use a count label. Runtime tests check 0/1/2.
- Brazilian Portuguese uses `lance`, `partida`, `dama`, `roque curto/longo`, `pré-lances` and `variante`, following Lichess and Brazilian chess sources. `Direitos de roque` and `Casa-alvo de en passant` preserve FEN semantics. Durations use invariant `s`; completed-position progress uses a count label. Explicit `=0` plural branches are required: Flutter generates `one` even for an ARB `=1` branch, and Portuguese classifies zero in that category. Runtime tests cover 0/1/2. The sole `pt` catalog is explicitly labelled Português (Brasil); pt-BR and other Portuguese device variants share it.
- Native shared spellings (`START`, German W for Weiß, French Minutes/Licence/Position) and canonical technical names are explicitly allowed by the untranslated-text guard. Game notation, PGN/FEN, engine protocols and diagnostic data remain canonical.

## Validation and remaining review

Automated coverage includes complete catalogs, Flutter ICU generation, language selection and restart, regional fallback, compact Home/settings at 200% text, board-editor layout at 200%, sampling help, classification labels, localized deletion dialogs, number formatting, and preservation of exported PGN. See [the localization guide](L10N_REVIEW.md) for commands and test files.

Validation on this revision: Flutter 3.47.5 localization generation and analyzer pass; **662 Flutter tests** and **40 Python tool tests** pass; catalog/CSV contracts pass for all ten catalogs. An ARM64 Dev debug APK built successfully using the existing pinned toolchain and hash-verified models. No dependencies were added.

Human reviewers should prioritize long sampling explanations, classification accessibility wording, Chessnut physical-board prompts, and their regional language preferences. A source citation or passing test is not native approval; TalkBack and physical-board behavior still need review in context.

## Android layout evidence

The API 36 ARM64 emulator was checked with Android fonts. Home and Settings were inspected in each new language. At a 320×568 logical screen with system font scale 2.0, the Russian side selector exposed clipping inside the original rounded outline. It now stacks vertically with a rounded rectangle when space is tight, and selecting Random remains readable. Host tests exercise selection and scrolling in all ten locales; native screenshots check the shape/font behavior that test fonts missed.
