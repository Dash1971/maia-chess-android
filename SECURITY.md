# Security reporting

Report suspected vulnerabilities privately through
[Security → Report a vulnerability](https://github.com/Dash1971/maia-chess-android/security/advisories/new).
Do not put exploit details, keys or private game/device data in a public issue.
Private vulnerability reporting is enabled for this repository.

Include the affected version/channel, reproduction steps, impact and a minimal
example. The maintainer will coordinate a fix and disclosure with the reporter.
Ordinary bugs belong in the issue tracker.

Security fixes target the latest published Stable release. Preview reports are also welcome through [Preview private reporting](https://github.com/Dash1971/maia-chess-android-preview/security/advisories/new); identify the channel so the issue can be checked in both.

For the official APK signer and file checks, see [Verify your download](docs/VERIFY_DOWNLOAD.md).
